# macOS Community DMG design

## Intent
Make the user's memory-optimization fork usable as a macOS DMG with every
implemented compatible optimization enabled, rather than packaging only an
observer. Preserve the installed official app and the existing Linux build.

## Architecture
Use the audited signed macOS ARM64 app as input. Verify SHA-256, signing team,
version, architecture and ASAR header integrity. Copy into an owned staging area.
Append a new bootstrap and package.json to ASAR without rewriting original entry
bytes. Recalculate integrity; never disable integrity fuses. A native launcher
passes a 512 MiB V8 old-space setting before the original Electron starts.
The bootstrap integrates the existing footprint/pressure helper and a scoped
window adapter. A profile explicitly separates enabled and unported features.
Sign all nested code inside-out and create/verify a DMG only after real app boot.

## Defaults and limits
Native footprint and pressure policy, background throttling, reduced Markdown
motion, offscreen paint skipping, idle hidden-window cache release and bounded
private telemetry are on. No new page-visible APIs, auth bypass, broad process
killer, transcript mutation, or remote-content CSS injection. Release is rate
limited. macOS has no claimed per-conversation 1 GiB kernel cap. 500–900 MiB is
still an unverified workload target. cgroups/inotify/Linux reapers and unconnected
MCP/tool/React modules are NOT marked enabled. Full app is ARM64, not universal.

## Distribution and validation
Development ad-hoc signature, not official signing/notarization. No installed
app mutation. Team-bound entitlements fail rather than impersonating a signer.
Preserve native bundle contracts; warn against concurrent official/Community
launch and about Keychain/deep-link/native integration differences. Provide safe
mode and retain official fallback. Upstream updates may remove modifications.
Portable parser/policy/regression tests plus actual macOS compiler, signing,
unauthenticated boot, runtime-hook checks and DMG remount verification are gates.
No claim of authenticated agent or Intel/long-session performance verification.
