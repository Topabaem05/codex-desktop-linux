Codex Community — experimental Apple Silicon / macOS 13+ development build

Quit official Codex/ChatGPT first. Drag Codex Community.app to Applications.
Keep the original app as a fallback; do not run the copies concurrently.
The built app does not need separately installed Node, Python or Xcode. Upstream
may download extra runtime/plugins on first launch.

Default ON: 512 MiB V8 old-space tuning, native footprint/pressure observation,
background throttle, reduced Markdown animations, offscreen paint skipping,
hidden-idle unused cache release under pressure, bounded status diagnostics.
This is NOT a macOS per-agent 1 GiB hard limit; 500–900 MiB remains unverified.
Linux-only and unfinished integrations are listed in community/profile.json.
Account features/system permissions remain controlled by OpenAI and the user.

Ad-hoc signing is NOT Developer ID signing/notarization or an official release.
Original APNs, app-group and shared-Keychain authority claims are removed.
Remote push is unavailable; login/native integration compatibility is unverified.
Use the system's per-app approval only after verifying source/SHA256SUMS.
Do NOT disable Gatekeeper/SIP/sandbox/TLS. Official app is the rollback path.

Safe mode, after quitting Community:
  open -a '/Applications/Codex Community.app' --args --community-safe-mode
Status: ~/Library/Application Support/Codex Community/memory/status.json
Upstream automatic updates may remove modifications; rebuild the reviewed port.
